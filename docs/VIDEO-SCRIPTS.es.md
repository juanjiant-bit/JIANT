# JIANT FM — Guiones de video: primeros pasos

Seis videos cortos, uno por cada recorrido de [FIRST-STEPS.es.md](FIRST-STEPS.es.md), para JIANT FM V10.8.48.
Cada uno dura entre 2 y 4 minutos. Las columnas son: **Tiempo** (aproximado), **En pantalla** (qué muestra la cámara:
el panel, la pantalla del FM-1 o los dos), **Juan dice** (frases cortas, para decirlas con tus palabras) y **Botones**
(lo que se toca, exacto).

Antes de grabar cada video, prendé el FM-1 desde cero para que arranque como en la guía (T1 batería, T2 ANALOG, T3 PHASE,
T4 FM6, sin pasos). Cuando aparezca un nombre o un mensaje del equipo, mostralo en primer plano un segundo.
*English version: [VIDEO-SCRIPTS.md](VIDEO-SCRIPTS.md).*
