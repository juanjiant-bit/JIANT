# JIANT FM — Video scripts: first steps

Six short videos, one for each tour of [FIRST-STEPS.md](FIRST-STEPS.md), for JIANT FM V10.8.48. Each one runs 2 to
4 minutes. The columns are: **Time** (approximate), **On screen** (what the camera shows: the panel, the FM-1's
screen, or both), **Juan says** (short lines, to be said in your own words) and **Buttons** (exactly what is pressed).

Before recording each video, power the FM-1 on from scratch so it starts as in the guide (T1 drums, T2 ANALOG,
T3 PHASE, T4 FM6, no steps). Whenever a name or a message from the device appears, show it close up for a second.
*Versión en español: [VIDEO-SCRIPTS.es.md](VIDEO-SCRIPTS.es.md).*
